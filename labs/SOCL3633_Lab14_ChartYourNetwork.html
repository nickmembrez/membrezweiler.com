Load and measure: Steps 1 to 3

Step 1: load your two files

Put alters in the blank in nrow(____) and run it, then run nrow(ties). The first number is how many people you named; the second is how many pairs of them know each other.

Checkpoint. With the practice files, both numbers are 8: eight people and eight ties.

Step 2: build the network

Run the graph_from_data_frame() line, then net. R joins your two files into one network: each person is a node, and each tie connects two nodes. The first line of the summary shows the number of people and ties, such as 8 8.

Step 3: how connected is your network?

Put net in the blank in edge_density(____) and run it. Then run the three lines below it, which compute the same number by hand.

Density
The number of ties divided by the number of possible pairs. With 8 people there are 8 × 7 ÷ 2 = 28 possible pairs, the same count as the tie generator in Lab 13. A density of 1 means everyone knows everyone; 0 means nobody knows anybody else.
Checkpoint. With the practice files, density is 0.2857: 8 ties out of 28 possible pairs. Ego is not counted, because you are tied to everyone by definition.

Draw your network: Step 4

No blanks. Run the set.seed() and layout_with_fr() lines, then select all the lines of the plot() command and run them. The drawing appears in the Plots pane. Click Zoom to see it larger.

This is the practice network. You are not in the drawing: these are the ties among the people you named. Look for three things. Groups of people who all know each other (MA, DA, LR). A bridge, a person who is the only link between two groups (JT). An isolate, a person tied to no one else (AN).

Then run components(net)$no, which counts the separate pieces of the network, and degree(net), which shows how many others each person is tied to.

Checkpoint. With the practice files, the network has 2 pieces (everyone else, and AN alone). LR and KB have the highest degree, 3. AN has 0.
Your drawing will look different, and that is the point. If everyone you named knows everyone else, you will see one tight cluster. If nobody knows anybody, you will see separate dots. Both are real results.

Color and save: Steps 5 and 6

Step 5: which question named each person?

  1. Run the alters$named_by <- ifelse(...) lines. They make a new column that says whether each person was named for important matters, for job help, or for both.
  2. Put named_by in the blank in table(alters$____) and run it.
  3. Run the group_colors lines and the V(net)$color line, then the plot() and legend() lines.
The people stay in the same places as in Step 4; only the color changes. In the practice network, the important-matters people sit in one group and the job-help people in the other, and the two people named for both are the ones who connect them. Look at where the colors fall in yours.

Step 6: save the colored drawing

  1. In the png( line, replace lastname with your last name, for example smith_lab14_network.png.
  2. Select every line from png( to dev.off() and run them together. Nothing appears in the Plots pane; the picture is saved in your SOCL3633 folder.
  3. Find the file in the Files pane and click it to check that it opens.
