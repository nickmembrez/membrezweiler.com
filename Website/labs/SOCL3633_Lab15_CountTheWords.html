Count the words: Steps 2 and 3

Step 2: one row per word

Put text in the blank in unnest_tokens(word, ____) and run the lines, then nrow(words).

unnest_tokens()
Splits each text into single words, one word per row, and makes every word lowercase. The unit of analysis changes: before this step each row was a text, and after it each row is a word.
Checkpoint. nrow(words) prints 1097: the 20 texts hold 1,097 words.

Step 3: count the words

Run count(words, word, sort = TRUE). The top of the list is "the," "to," and "a." These are stop words: words that hold sentences together but say little about the topic. Run the anti_join(stop_words, ...) lines to remove them, then count again.

Checkpoint. After removing stop words, the top five are defendant (21), sophisticated (12), means (10), defendant's (9), and conduct (6).
Look at why "defendant" is first. On the handout, every defendant's name was replaced with [the defendant] to protect privacy. The most frequent word in the corpus was partly created by how the corpus was prepared. A word count measures the texts you give it, including your own edits.

Chart them: Step 4

  1. Run the top_words lines. They keep every word that appears at least 4 times.
  2. Run the chart lines and print(words_chart).
  3. Replace the title with a short complete sentence, about ten words, that says what the words show. Run the chart lines again.
  4. In the ggsave() line, replace lastname with your last name and run it.
This is the chart from the answer key. Yours has the same bars and your own title. Notice what the chart cannot tell you: whether a text calls the conduct sophisticated or argues that it was not. Text 9 uses "sophisticated" to say "there is nothing sophisticated" about the conduct. The count treats both uses the same. Question 3 on the response sheet asks about this.

A word list as a second coder: Step 5

A content dictionary is a list of words that stand for one idea. The computer marks a text 1 if any word on the list appears in it, and 0 if none does. Today's list is for hiding or concealment.

  1. Run the ten, my_words, and pattern lines, then the flags lines, then flags. The word_list column shows the computer's call for each of the ten texts.
  2. Find the column on your Tuesday grid for the code closest to hiding or concealment. In the my_codes <- c(____) blank, type its ten values, 1 or 0, separated by commas, in grid order. Run it, then the next two lines.
  3. Run sum(flags$word_list == flags$my_code): the number of texts, out of 10, where you and the word list agree.
  4. Add one word beginning to my_words that you think the list is missing, such as "evad" or "avoid". Run Step 5 again from the my_words line and see whether the count changes.
Checkpoint. With the starting list, the word list marks only texts 10 and 17. The answer key codes hiding in texts 9, 10, 11, and 17, so they agree on 8 of 10. Adding "evad" and "avoid" catches text 11 and raises it to 9 of 10. Text 9 is still missed: it describes moving money so it cannot be recovered, without any word on the list.
