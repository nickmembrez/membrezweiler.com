Grouping Categories SOCL 3633 Research Methods · Lab 4 · Midwestern State University

Researchers often combine the categories of a variable into a few groups. That is a measurement decision, and it can change the answer. Today you group the same party answers in two ways, group the religion answers your own way, and read four real GSS questions closely. Keep this page open next to RStudio and work through the tabs in order. Before you leave, you submit two things in the Lab 4 submission on D2L: your response sheet and the picture file of your own chart.

Get set up

One new tool today

fct_collapse()
Combines the categories of a variable into new groups. Each line inside it reads: "new group name" = c("old category", "old category"). Anything you do not list goes into the group named by other_level.
mutate()
Adds a new column to the data. Here the new column holds the grouped version of the variable, so the original stays unchanged.

If something goes wrong

What you seeWhat to do
A warning that says "Unknown levels"A category name is misspelled. Copy it exactly from the Step 2 output, including the comma and lower-case letters: Ind,near dem.
Version B shows 674 people in "All other answers"The two blanks are still empty or misspelled, so the leaners went into "All other answers." Fix the names and run the six lines again.
"unexpected symbol"A quotation mark or comma is missing. Each category is in quotation marks, with a comma between categories.
A + sign in the Console and nothing happensA parenthesis is missing. Press Escape in the Console, fix the line, and run all six lines again.
"object 'gss_2014' not found"Step 2 did not run. Run it, then come back.
